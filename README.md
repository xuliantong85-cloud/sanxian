# 标普·沪深·恒科三线读盘

用布林线、RSI 和偏离度分析标普500、纳斯达克100、沪深300、恒生科技指数和浦发银行，并给出分周期的后市判断。

## 文件

| 文件 | 内容 |
| --- | --- |
| `index.html` | claude.ai 版网页（可刷新数据、保存 EODHD 密钥、Claude 解读） |
| `public/index.html` | 公开版网页，发布在 GitHub Pages，只显示每天自动更新的数据 |

| `snap_ndx.txt` | 纳斯达克100 数据快照（腾讯行情，2016-10 起；2021-05 缺的 10 天用新浪财经补齐） |
| `snap_csi300.txt` | 沪深300 数据快照（2016-02 起） |

## 分红股估值看板（public/value.html）

判断长期持有的分红股现在偏贵还是偏便宜。每只股票和自己近 5 年的历史比（数据从 2018 年起保存，基准期由 value_page.html 里的 BASE_YEARS 决定），再和 10 年期国债收益率比。

| 文件 | 内容 |
| --- | --- |
| `stocks.json` | 看板里的股票。加一行（代码、名称、备注），下次每日更新会自动拉取它的全部历史 |
| `value_data.py` | 从东方财富数据中心拉每日估值、分红和国债收益率 |
| `valuecore.js` | 计算股息率、历史分位、估值温度和参考价（纯函数，可用 Node.js 测试） |
| `value_page.html` | 看板网页模板 |
| `val_<代码>.txt` | 每日估值：`日期:收盘价:市盈率TTM:市净率` |
| `div_<代码>.txt` | 分红：`除息日:每股税前派息:是否年度末期分红(1/0)` |
| `bond10y.txt` | 中国 10 年期国债收益率（%） |

- **估值温度**（0–100，越低越便宜）= 平均（市盈率分位，市净率分位，1 − 股息率分位）× 100。低于 40 偏低，高于 60 偏高。
- **股息率** = 每股年度分红 ÷ 收盘价；每股年度分红 = 最近一次年度末期分红 + 最近一次中期分红（各自 15 个月内派发的才算）。不用滚动 365 天求和，因为除息日每年会前后挪动，会让股息率忽高忽低。
- **息差** = 股息率 − 10 年期国债收益率，纠正利率下行让分红股整体变贵的影响。
- **参考价**：把三项估值放回历史 20% / 50% / 80% 分位换算成股价后取平均。

## 每日自动更新

GitHub Actions 在周一至周五 23:00 UTC（北京时间次日 7:00）运行：

1. `update.py` 读取新数据：
   - 沪深300、恒生科技：腾讯行情日 K 线；读不到时改用东方财富。
   - 纳指100：腾讯行情日 K 线；读不到时改用 EODHD 的 NDX.INDX。
   - 浦发银行：腾讯行情不复权收盘价（新浪备用），并刷新新浪前复权因子。不用腾讯自带的前复权价，因为它按"减去分红"调整，会放大涨跌幅。
   - 新数据单日涨跌超过 50% 时，视为数据源出错，改用下一个数据源。腾讯 `us.NDX` 的当日行情曾混入别的股票。
   - 标普500：EODHD 的 GSPC.INDX（FRED 不允许脚本访问）。需要在仓库的 Settings → Secrets and variables → Actions 里设置 `EODHD_KEY`。
2. 把更新后的快照提交回仓库。
3. `encrypt.js` 用访问密码加密公开版网页。密码在 Secrets 里设置为 `PAGE_PASSWORD`；没有设置时这一步失败，不会发布未加密的网页。
4. 把 `public/` 发布到 GitHub Pages。

### 访问密码

- 打开网址先看到密码页，输对密码后，浏览器在本地解密并显示网页（PBKDF2-SHA256 + AES-256-GCM）。
- 勾选"记住密码"后，同一台设备下次打开会自动进入。
- 改密码：在 Secrets 里更新 `PAGE_PASSWORD`，再手动运行一次「每日更新」。之前记住的旧密码会失效，需要重新输入。
- 限制：仓库是公开的，代码和行情数据快照在仓库里都能看到；密码只保护这个网址。

也可以在仓库的 Actions 页面选「每日更新」→ Run workflow 手动运行。

## 本地修改后重新生成网页

```
python3 build.py
```

在本地手动更新数据（不设置 `EODHD_KEY` 时只更新沪深300和恒生科技）：

```
EODHD_KEY=你的密钥 python3 update.py
```

## 两个版本的区别

- **claude.ai 版**（`index.html`）：在 Claude 桌面应用里打开，可以用内置浏览器刷新数据、保存 EODHD 密钥、生成 Claude 解读。
- **公开版**（`public/index.html`）：任何人都能打开，不需要登录；没有刷新按钮和 Claude 解读，数据每天由 GitHub 定时任务更新。

本工具基于历史价格计算技术指标，不构成投资建议。
